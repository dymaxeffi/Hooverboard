# Simulation (ab Phase 3)

Simulationen importieren **ausschliesslich** `calculations/hoverlib` (Formeln, Parameter). Keine eigenen Formelkopien.

Geplant: Heave-/Kippdynamik des Kissens (gekoppelte ODE Plenumdruck–Höhe–Neigung), Gebläsekennlinie aus A0-Messung, Fehlerfälle (Gebläseausfall, Lastsprung), Parameterstudien Grösse/Masse/Leistung.
Ergebnisse werden als **Simulation** gekennzeichnet, nie als experimenteller Nachweis.
